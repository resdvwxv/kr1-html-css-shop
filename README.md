# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».
Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

В проекте реализован многостраничный HTML/CSS-сайт с семантической разметкой, формами, модальным окном, Flexbox/Grid раскладками и БЭМ-именованием классов.

## Структура проекта

```
kr1-html-css-shop/
├── index.html        — главная страница (hero-блок, преимущества, популярные товары)
├── catalog.html      — каталог товаров с фильтрами
├── product.html      — карточка товара с таблицей характеристик
├── order.html        — страница оформления заявки
├── contacts.html     — контактная информация и обратная связь
├── bitubisas.html    — цифровая лицензия «Битубизес»
├── morkovnye-piatki.html — зазеркальное блюдо «Морковные пятки»
├── css/
│   └── style.css     — общие стили (переменные, компоненты, состояния)
├── js/
│   └── main.js       — модалка, валидация, загрузка шапки, скролл-наверх
├── images/           — изображения товаров и иконок
├── partials/
│   └── header.html   — шапка сайта (подгружается через fetch)
├── favicon.svg       — фиолетовый кристалл
├── README.md         — описание проекта
└── .gitignore        — исключения Git
```

## Технологии

- **HTML5** — семантическая разметка (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`)
- **CSS3** — внешний файл стилей, CSS-переменные (`:root`), состояния (`:hover`, `:focus-visible`, `:disabled`)
- **Flexbox** — горизонтальная навигация, выравнивание элементов
- **CSS Grid** — сетка карточек товаров (`products-grid`), раскладка каталога (`catalog-layout`)
- **БЭМ** — методология именования классов (блок, элемент, модификатор)
- **Позиционирование** — `sticky` (шапка), `fixed` (кнопка «Наверх»), `relative` + `absolute` (бейдж карточки)
- **Формы** — валидация через HTML5-атрибуты (`required`, `type`, `pattern`), `<dialog>` модальное окно, JS-валидация
- **JavaScript** — открытие/закрытие модального окна, обработка отправки формы, плавная прокрутка

## Как проверить проект

1. Откройте файл `index.html` в браузере (или любую другую страницу).
2. Проверьте навигацию — все страницы связаны между собой единым меню.
3. Проверьте якорные ссылки на главной: «Преимущества», «Популярные товары».
4. Перейдите в «Каталог» — карточки товаров выстроены через CSS Grid.
5. Откройте страницу «Товар» — таблица характеристик, кнопка заявки открывает модальное окно.
6. Страница «Заявка» — полная форма оформления заказа с валидацией.
7. В консоли браузера ошибок быть не должно.

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

| Блок | Назначение |
|------|-----------|
| `site-header` | шапка сайта |
| `site-nav` | основная навигация |
| `breadcrumbs` | хлебные крошки |
| `hero` | первый экран главной страницы |
| `products-grid` | сетка товаров |
| `product-card` | карточка товара |
| `product-card__badge` | бейдж на карточке (Новинка, Скидка) |
| `catalog-layout` | структура страницы каталога (фильтры + товары) |
| `catalog-filters` | фильтры каталога |
| `order-dialog` | модальное окно заявки (`<dialog>`) |
| `order-form` | форма заявки |
| `product-detail` | страница карточки товара |
| `scroll-top` | кнопка «Наверх» (фиксированная) |
| `button` | кнопка (primary / secondary) |
| `site-footer` | подвал сайта |

**Тема:** «HTML и CSS: разработка многостраничного сайта».

**Выполнено:**

- Flexbox (навигация, кнопки) и CSS Grid (карточки, каталог)

- Позиционирование: `sticky` шапка, `fixed` кнопка «Наверх», `relative`/`absolute` бейдж
